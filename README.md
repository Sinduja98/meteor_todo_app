**Simple To-Do App**

A basic to-do list application built with Meteor and Blaze/React, allowing users to add, remove, and manage tasks in real-time.

Features:
- Add and remove tasks easily
-  Mark tasks as completed
-  Simple and clean UI

Installation and Setup:

1. Clone the repository:
    - git clone https://github.com/Sinduja98/meteor_todo_app.git
    - cd simple-todos-kuna
2. Install Meteor (if not already installed):
   - curl https://install.meteor.com/ | sh
3. Run the application:
   - meteor run
4. Open in the browser:
   - Visit http://localhost:3000 in your web browser.
